COMPONENTES DEL BACKEND (dentro del repositorio backend):

1. API Gateway (BFF)
   Ruta: /SanosySalvos-Backend/SanosySalvos-Backend/api-gateway
   Puerto: 8080
   Descripción: Backend For Frontend. Punto de entrada único
   para el frontend. Enruta peticiones hacia los microservicios
   y valida tokens JWT mediante AuthFilter.

2. User Service
   Ruta: /SanosySalvos-Backend/SanosySalvos-Backend/user-service
   Puerto: 8081
   Descripción: Microservicio de autenticación. Gestiona registro
   y login de usuarios con Spring Security, BCrypt y JWT.
   Incluye pruebas unitarias para AuthService y JwtService.

3. Lost Pet Service
   Ruta: /SanosySalvos-Backend/SanosySalvos-Backend/lost-pet-service
   Puerto: 8082
   Descripción: Microservicio para registrar y gestionar reportes
   de mascotas perdidas.

4. Found Pet Service
   Ruta: /SanosySalvos-Backend/SanosySalvos-Backend/found-pet-service
   Puerto: 8083
   Descripción: Microservicio para registrar y gestionar reportes
   de mascotas encontradas.

5. Matching Service
   Ruta: /SanosySalvos-Backend/SanosySalvos-Backend/matching-service
   Puerto: 8084
   Descripción: Microservicio que cruza reportes de mascotas
   perdidas con encontradas para detectar coincidencias.
   Se comunica con lost-pet-service y found-pet-service via HTTP.

6. Notification Service
   Ruta: /SanosySalvos-Backend/SanosySalvos-Backend/notification-service
   Puerto: 8086
   Descripción: Microservicio para envío de notificaciones
   por correo electrónico a los usuarios.
